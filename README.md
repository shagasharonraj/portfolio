# Personal Portfolio Website

##  Project Description

This project is a **responsive personal portfolio website** created using HTML, CSS, and JavaScript. It showcases personal information, skills, projects, and contact details in a clean and simple design.

The website is designed to work properly on **desktop, tablet, and mobile devices**.

##  Key Features

* Responsive design for different screen sizes
* About Me section
* Skills section
* Projects section
* Contact section
* Navigation bar
* Smooth scrolling between sections
* Hover effects and simple animations
* Mobile-friendly layout
* Clean and user-friendly interface

##  Technologies Used

* **HTML5** – Structure of the website
* **CSS3** – Styling and responsive design
* **JavaScript** – Interactivity and navigation

##  Project Structure

```text
portfolio/
│
├── index.html
├── style.css
└── script.js
```

##  How to Run the Project

1. Download or clone the project.
2. Keep all three files in the same folder.
3. Open the `index.html` file in any web browser.
4. The portfolio website will open and can be viewed directly.

##  Responsive Design

The website is designed to adapt to:

* Desktop screens
* Tablet screens
* Mobile screens

CSS Flexbox/Grid and media queries are used to make the layout responsive.

##  Project Objective

The main objective of this project is to create a simple and professional online portfolio that presents personal information, technical skills, projects, and contact information in an organized manner.
